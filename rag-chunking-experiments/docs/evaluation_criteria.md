# 평가 기준

## 1. 검색 성능 메트릭

### 1.1 Precision@k

검색된 상위 k개 중 관련 문서의 비율

```
Precision@k = |관련 ∩ 검색된_k개| / k
```

**예시**: Top-5 중 3개가 관련 → Precision@5 = 3/5 = 0.6

### 1.2 Recall@k

전체 관련 문서 중 검색된 비율

```
Recall@k = |관련 ∩ 검색된_k개| / |관련|
```

**예시**: 관련 문서 4개 중 3개 검색 → Recall@5 = 3/4 = 0.75

### 1.3 F1@k

Precision과 Recall의 조화 평균

```
F1@k = 2 × (Precision × Recall) / (Precision + Recall)
```

### 1.4 MRR (Mean Reciprocal Rank)

첫 번째 관련 문서의 순위의 역수

```
MRR = 1 / (첫 번째 관련 문서 순위)
```

**예시**: 관련 문서가 3위에 등장 → MRR = 1/3 = 0.33

### 1.5 NDCG@k

순위에 따른 가중 관련성 점수

```
DCG@k = Σ (rel_i / log2(i+1))
NDCG@k = DCG@k / IDCG@k
```

## 2. 청크 품질 메트릭

### 2.1 크기 통계

| 메트릭 | 설명 | 이상적인 값 |
|--------|------|------------|
| 평균 크기 | 청크당 평균 단어 수 | 300-700 words |
| 표준편차 | 크기 분산 | 낮을수록 좋음 |
| 최소/최대 | 극단값 | 과도하게 작거나 크지 않음 |

### 2.2 균일성 (Uniformity)

```
Uniformity = 1 - (표준편차 / 평균)
```

- 1에 가까울수록 균일
- Fixed: ~0.95+ (매우 균일)
- Recursive: ~0.70-0.85
- Semantic: ~0.60-0.75

### 2.3 문맥 보존

정성적 평가:
- 문장이 중간에서 끊기지 않음
- 관련 정보가 같은 청크에 포함
- 논리적 흐름 유지

## 3. 처리 효율성 메트릭

### 3.1 처리 시간

```
처리 시간 = 전체 청킹 소요 시간 (초)
```

### 3.2 처리량

```
처리량 = 생성된 청크 수 / 처리 시간 (chunks/sec)
```

### 3.3 상대적 복잡도

| 전략 | 시간 복잡도 |
|------|------------|
| Fixed | O(n) - 선형 |
| Recursive | O(n log n) - 준선형 |
| Semantic | O(n²) - 이차 (임베딩 계산) |

## 4. 종합 평가 기준

### 4.1 가중치 기반 점수

```python
score = (
    0.4 × F1@5 +
    0.2 × MRR +
    0.2 × Uniformity +
    0.2 × (1 / log10(처리시간 + 1))
)
```

### 4.2 사용 사례별 평가

| 사용 사례 | 중요 메트릭 | 권장 전략 |
|----------|------------|----------|
| 실시간 검색 | 처리 속도, F1 | Fixed |
| 문서 검색 | F1, MRR | Recursive |
| 고품질 QA | MRR, NDCG | Semantic |

## 5. 테스트 쿼리 설계 기준

### 5.1 카테고리별 분포

| 카테고리 | 비율 | 설명 |
|----------|------|------|
| 사실 질문 | 40% | 단순 정보 검색 |
| 절차 질문 | 30% | How-to 질문 |
| 비교 질문 | 20% | A vs B 질문 |
| 복합 질문 | 10% | 다중 정보 필요 |

### 5.2 난이도별 분포

| 난이도 | 비율 | 설명 |
|--------|------|------|
| Easy | 40% | 단일 청크에서 답변 |
| Medium | 40% | 2-3개 청크 참조 |
| Hard | 20% | 여러 문서 통합 필요 |

## 6. Ground Truth 작성 가이드

### 6.1 관련성 판단 기준

- **High**: 질문에 직접적인 답변 포함
- **Medium**: 답변에 도움이 되는 정보 포함
- **Low**: 간접적으로 관련

### 6.2 예시

```json
{
  "query_id": "Q001",
  "query": "토마토 재배에 적합한 온도는?",
  "relevant_chunks": [
    {"chunk_id": "doc1_chunk_03", "relevance": "high"},
    {"chunk_id": "doc1_chunk_04", "relevance": "medium"}
  ]
}
```
